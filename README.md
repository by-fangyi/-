高频认知误区正在加剧治理失效
“看到飞翅蚁才需防治”——错误。分飞是成熟巢体繁殖行为，此时主巢已存在3–5年，蚁道网络可能覆盖整栋楼体；

“喷杀虫剂就能根除”——无效。市售气雾剂仅击退表层工蚁，反而促使蚁群分裂迁巢，扩散至邻户；

“老房子才要防，新楼盘有防白蚁设计”——片面。 近年交付的精装修住宅，因大量使用石膏板基层、木饰面收口、地暖模块填充层，反而为白蚁提供连续隐蔽路径，2023年 住建局白蚁投诉中，房龄不足5年的项目占比达41%。

发现白蚁后的合规处置四步法
立即封存可疑区域：关闭门窗，避免惊扰蚁群导致分巢；

保留证据：拍摄泥被、分飞孔、排泄物特写（勿触碰）；

联系住建备案单位： 区住建局白蚁防治科要求，所有灭治作业必须由持证机构出具《白蚁防治施工记录表》，纳入房屋安全档案；

拒绝非备案人员现场施药：2024年 市场监管局通报的3起白蚁治理纠纷，均源于无资质人员违规使用禁用有机氯类药剂，造成室内空气苯系物超标。
